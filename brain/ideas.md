# The idea shelf

New business ideas go here first, so they don't take time from the
projects you're already running. An idea on the shelf never goes
overdue.

How it works:

- Write each idea the day you have it: the date, then a short
  paragraph.
- It becomes a project only if you still want it **two weeks later**
  and can say what it would replace.
- If you drop an idea, mark it `dead` and add one line on why, so you
  remember the reason later.
