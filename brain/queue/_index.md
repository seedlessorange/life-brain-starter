# The queue

Requests written from the page's **Ask Claude** box land here as one file
each. Writing one calls no AI and costs nothing — they sit here until you run
`/queue` in Claude Code (or press **Work the queue now** on the page).

Never delete a queue file. Mark it `done` or `dropped` in its frontmatter,
with an `## Outcome` section saying what happened — the page shows that
outcome on the card, and it is the only report the asker gets.
